# Glossary

The terms Levy's code, API and docs use, in alphabetical order, with where each appears. Amounts everywhere are integers in 6-decimal USDC units (see the first entry). For how the parts fit together see [Architecture](Architecture.md).

| Term | Meaning | Where it appears |
|---|---|---|
| 6-decimal units | USDC amounts as integers with six decimals, through the ERC-20 interface: 1 USDC = 1,000,000 units, so 10 USDC is `10000000`. Arc's native 18-decimal gas balance never enters payment logic | every `price`, `amount`, `fee` and `credit`; `formatUsdc` in `api/src/server.ts`; the decimals check in `script/Deploy.s.sol` |
| Account owner | Who acts for a merchant account: creates plans under it, retires them, pauses, resumes and cancels for it, sets its payout and hands it on. The account itself until `acceptOwnership` moves it, in two steps after `transferOwnership` | `ownerOf`, `pendingOwner`, `merchant_accounts` table |
| Advance billing | Each pull pays for the cycle that starts at it. With no trial the first cycle is pulled at subscribe (a failed pull reverts with `PaymentFailed`); a plan change bills the new plan at once | `_subscribe`, `_collect`, `changePlan` |
| Allowance | The USDC ERC-20 allowance a subscriber grants the SubscriptionManager: one pool shared by all of their Levy subscriptions, and the ceiling on what Levy can pull | `_tryPull`; the checkout approves N payments (default 12, at most a limited plan's payments, intro payments at the intro price) on top of the existing allowance |
| Allowance runway | How many rounds of charges the allowance covers: the allowance divided by the next charge of each of the subscriber's chargeable subscriptions, at the intro price for an intro cycle. It is flagged `low` when the allowance does not cover the next 2 charges of all of them, counting none past a limited plan's last, and each affected subscription's merchant then gets one `allowance.low` webhook. Only direct allowances count, so Permit2 subscribers read as low | `keeper/src/funds.ts`, `subscriber_funds` table, `GET /api/funds` |
| Arc | The L1 Levy runs on; USDC is its gas token. Chain ID 5042 (mainnet) and 5042002 (testnet), about 0.5 s blocks, single-block finality | `.env` files, `api/public/wallet.js`, `VERIFICATION.md` |
| Auto-pause | The contract moves a subscription to PAUSED and emits `AutoPaused` when `failedAttempts` reaches twice `maxFailed`. It happens inside `charge()`; the keeper never pauses anything. Only the subscriber can resume it | `_recordFailure` |
| Backoff | The keeper's delay before retrying a charge that failed for a non-payment reason (a revert or RPC error): 1 min, 5 min, 15 min, 1 h, then 6 h, in memory only. Not the dunning schedule | `ERROR_BACKOFF_SEC` in `keeper/src/keeper.ts` |
| billedPrice | Public view: the price billed for a subscription's cycle in progress, the plan's price or its intro price. Written on every billed cycle, including one paid from credit, and the price a plan change credits unused time at | `SubscriptionManager.billedPrice`, `_collect`, `changePlan` |
| Chain time | The timestamp of the latest block. The keeper uses it, not the wall clock, for due and dunning math | `Indexer.sync` (`nowSec`) |
| Charge | `charge(subId)`: pulls one cycle of a due subscription. Permissionless; the keeper is the usual caller. Each success is also a row in `charges` | `SubscriptionManager.charge`, `Keeper.tryCharge` |
| COMPLETED | Status 5, set by the billing routine when a limited plan's last cycle is billed, with the `Completed` event. Terminal like CANCELLED; `nextChargeAt` then marks the end of the last paid cycle, shown as "paid through" | `_collect`, `subscription.completed` webhook |
| Credit (proration) | The balance in `Subscription.credit`. A plan change adds `billedPrice x remainingSeconds / oldCycleSeconds`, rounded down, for unused paid time. It is spent before any pull and is always backed by USDC the subscription paid. Trial time earns none, and credit left at cancellation or completion is forfeited | `changePlan`, `_collect`, `invariant_creditBacked` |
| Cycle | The billing period, `cycleSeconds`, from `MIN_CYCLE` (1 day) to `MAX_CYCLE` (10 years). The dashboard's "Monthly" is a fixed 30 days | `Plan.cycleSeconds` |
| Dead letter | A webhook delivery given up on: status `dead` once its next retry would pass 24 hours of age (last attempt about 19 h 21 min), or when its webhook is deleted or deactivated | `webhook_deliveries.status`, `nextRetryAt` in `keeper/src/webhooks.ts` |
| Delivery id | `{16 hex digits}-{row id}`: a random prefix fixed per database and the `webhook_deliveries` row id, sent as `X-Levy-Delivery` and covered by the signature. It is the same across retries of one delivery and never reused, so receivers use it to drop duplicates | `signedContent`, `LevyDb.deliveryEpoch` |
| Dunning | Handling of failed payments: an on-chain failure counter with spaced recording, an off-chain retry schedule, and webhooks | `_recordFailure`, `retryGap`, `keeper/src/dunning.ts`, `dunning` table, `GET /api/dunning` |
| FEE_BPS | The constant `100`. Despite the name it is a divisor: `fee = amount / 100`, which is 1% rounded down; the merchant keeps the remainder | `_collect`, `FEE_MATH_AUDIT.md` |
| FeeRouter | The contract that receives the 1% fee and holds it until `sweep()` | `src/FeeRouter.sol` |
| graceSeconds | A plan field before manager v2, stored on-chain and read by nothing. v2 dropped it from `createPlan` and the `Plan` struct; the testnet contracts from 2026-10-24 still take it | the pre-v2 `createPlan` |
| Intro price | `introPrice`, billed instead of `price` for a subscription's first `introCycles` billed cycles on the plan it subscribed to. Above 0 and below `price`; a trial comes first and does not count. A plan change clears the intro cycles left, so intro prices never carry over. Eligibility is per subscription and checked off-chain | `PlanTerms`, `introCyclesLeft`, `_collect` |
| Invoice | A `Charged` event recorded as a `charges` row: invoiceRef, subscription, amount, fee, transaction hash, block, charge count. Exported as CSV and announced by `invoice.ready` | `GET /api/invoices` |
| invoiceRef | The `bytes32` in `Charged`: `keccak256(abi.encode(subId, chargeCount))`. Deterministic and moves no funds | `_collect` |
| Keeper | The off-chain service in `keeper/`: indexes events, calls `charge()`, retries failures, checks allowance runway and delivers webhooks. It pays gas from its own key; run one instance | `keeper/src/index.ts` |
| Lookback | `LEVY_LOOKBACK_BLOCKS`, default 5000 (about 40 minutes): how far back the first sync scans when no cursor exists. Raise it to reach the deploy block | `keeper/src/config.ts` |
| maxCycles | Plan field (`uint32`, 0 for no limit): how many cycles a subscription is billed on the plan before it completes. `planCycles` counts them, including cycles paid from credit, and a plan change restarts the count. 1 with no trial is a one-time payment | `createPlan`, `planCycles`, `_collect` |
| maxFailed | Plan field (`uint8`, 1 to 255): the number of failures before PAST_DUE. Auto-pause comes at twice that | `createPlan`, `_recordFailure` |
| Merchant account | The address a plan was created for, and the plan's `merchant`: a permanent id for webhooks, the API and `changePlan`'s same-merchant rule. It has an owner and a payout, both changeable | `ownerOf`, `payoutOf`, `GET /api/accounts` |
| MIN_CYCLE | The constant 1 day, the shortest `cycleSeconds`. It bounds how often the keeper pays gas for one subscription | `createPlan` |
| nextChargeAt | The `uint64` time when the next cycle may be charged. A successful charge adds one cycle to the stored value, or sets it to now plus one cycle after failed attempts or a whole uncharged cycle; `changePlan` sets it to now plus the new cycle; resume moves a passed date to now. On a COMPLETED subscription it is the end of the last paid cycle | the `Subscription` struct |
| PAST_DUE | Status 2, set when `failedAttempts` reaches `maxFailed`. Still chargeable; a successful charge clears it | `_recordFailure` |
| pausedByMerchant | Public view, true while the subscription is paused by its merchant: set by `pauseSubscription`, cleared on resume. The merchant can resume only such a pause. The keeper mirrors it for PAUSED subscriptions, and the dashboard offers Resume only when it is 1 | `SubscriptionManager.pausedByMerchant`, `subscriptions` table |
| Payout | Where a merchant account's 99% goes: a fixed address set with `setPayout`, or the current owner while none is set (`accountPayout` reads zero). It applies from the next collection, and the manager's own address is refused | `payoutOf`, `accountPayout`, `_collect` |
| Permit2 | Uniswap's allowance contract at `0x000000000022D473030F116dDEE9F6B43aC78BA3`. A subscriber signs a `PermitSingle` naming the manager as spender and submits it through `subscribeWithPermit2`; the manager also falls back to Permit2 when the direct pull fails. Needs a one-time USDC approval to Permit2 | `src/IPermit2.sol`, `_tryPull`, `keeper/scripts/permit2-subscribe.mjs` |
| Plan | An on-chain offer with immutable terms: merchant account, price, `cycleSeconds`, `trialSeconds`, `maxFailed`, `maxCycles`, `introPrice`, `introCycles`, `transferable`. Only `retired` changes. It has no name on-chain, and a new price means a new plan | `createPlan`, `plans` table |
| ref | The merchant's own `bytes32` reference for a subscription: set at subscribe, stored in `subscriptionRef`, emitted in `Subscribed` and carried on every webhook. Public and chosen by whoever subscribes, so a claim, not proof. Checkout links take up to 31 ASCII characters or `0x` plus 64 hex digits | `subscribe`, `?ref=` on `checkout.html` |
| Retired plan | A plan closed to new subscriptions and plan changes into it (`RetiredPlan`) by `setPlanRetired`. Existing subscriptions carry on, and the owner can reopen it | `setPlanRetired`, `plans.retired` |
| retryGap | View `retryGap(failures)`: the shortest time between recorded failures, 0 before the first, then 1 day, 3 days and 7 days. The on-chain form of the dunning schedule | `SubscriptionManager.retryGap` |
| RetryTooSoon | The error from a failing `charge()` made before `lastFailedAt + retryGap`. It changes nothing, so strangers cannot speed up auto-pause. The keeper treats it as a non-payment error and backs off | `_recordFailure` |
| SIWE | Sign-In with Ethereum (EIP-4361). The server writes a message bound to `LEVY_PUBLIC_ORIGIN` and the chain, the wallet signs it, and a 24-hour session follows (cookie for the pages, bearer token for backends). EOA wallets only | `api/src/auth.ts`, `/api/auth/*` |
| Soak | The M4 testnet run: at least a week of real billing on the 2026-10-03 deployment, day 0 on 2026-10-07. Checklist and log in `ops/testnet-soak.md` | `ops/testnet-soak.md` |
| Soak wallets S1 to S5 | Test wallets for the soak: S1 the control, left alone; S2 trial, pause, resume, cancel; S3 a failing allowance (dunning, PAST_DUE, auto-pause, recovery); S4 plan changes; S5 Permit2 subscribe. A separate merchant wallet creates the plans | `ops/testnet-soak.md` |
| Status | The subscription state, stored as a number: TRIAL 0, ACTIVE 1, PAST_DUE 2, PAUSED 3, CANCELLED 4, COMPLETED 5. Cancelled and completed are final | `enum Status`, `subscriptions.status`, API `statusName` |
| Subscription | A subscriber's link to a plan: subscriber, planId, start, `nextChargeAt`, `failedAttempts`, credit, `chargeCount`, status | the `Subscription` struct, `subscriptions` table |
| Subscription transfer | Moving a subscription to a new wallet on a `transferable` plan: `proposeTransfer` by the subscriber, then `acceptTransfer(subId, planId)` by the new wallet. Only the subscriber changes; id, `ref`, paid time, credit and dunning state stay | `pendingTransfer`, `subscription.transferred` webhook |
| Sweep | `FeeRouter.sweep()` sends the router's whole USDC balance to the treasury. Anyone may call it; the destination is fixed | `FeeRouter.sweep`, event `Swept` |
| Treasury | The address that receives swept fees and the only one that can call `proposeTreasury`; the proposed address becomes treasury when it calls `acceptTreasury`. Mainnet requires a contract (a 2-of-3 Safe is planned); on testnet it is the deployer's key | `FeeRouter.treasury`, `FeeRouter.pendingTreasury`, `ops/treasury-multisig.md` |
| Trial | `trialSeconds`, shorter than the cycle: no charge at subscribe, status TRIAL, first charge at start plus trial. Trial time earns no credit | `_subscribe` |
| USDC | The stablecoin that is also Arc's gas token. Levy uses its ERC-20 face at `0x3600000000000000000000000000000000000000`, which has 6 decimals | `LEVY_USDC_ADDRESS`, `script/Deploy.s.sol` |
| Webhook | A signed HTTPS POST from the keeper to a merchant endpoint, one of thirteen event types, with `X-Levy-Signature`, `X-Levy-Timestamp`, `X-Levy-Delivery`, `X-Levy-Webhook`, `X-Levy-Key-Id` and `X-Levy-Event` headers (Ed25519 over `{timestamp}.{deliveryId}.{webhookId}.{event}.{body}`) | `keeper/src/webhooks.ts`, `webhooks` table |
